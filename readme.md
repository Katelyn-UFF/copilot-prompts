## 💻 Sobre o Projeto

Este repositório contém um **roadmap personalizado de 90 dias** para quem deseja crescer como **Analista de Dados**.  
O plano foi adaptado para uma carga de **3 horas semanais**, com foco em fundamentos, prática e construção de portfólio.

---

## 📚 Pré-requisitos de Habilidades e Níveis de Conhecimento

Antes de iniciar, é recomendado ter noções básicas de:

- Lógica de programação | Básico  
- Excel / Planilhas | Básico  
- Conceitos de banco de dados | Básico  

---

## 🛠️ Habilidades e Sub-habilidades que vamos aprender neste conteúdo

- SQL  
  - Consultas básicas e intermediárias  
- Excel avançado  
  - Tabelas dinâmicas e fórmulas  
- Power BI  
  - Dashboards e visualização de dados  
- Python (introdução)  
  - Pandas e manipulação de dados  

---

## 🎯 Objetivos e Resultados Esperados

Após a conclusão, você será capaz de:

- Criar consultas SQL para extrair e organizar dados  
- Construir dashboards interativos em Power BI  
- Realizar análises exploratórias com Python  
- Apresentar insights claros e objetivos para apoiar decisões  
- Ter um **projeto de portfólio** publicado no GitHub  

---

## 📅 Roadmap de 90 Dias

**Mês 1 - Fundamentos**  
- Semana 1-2: SQL básico (SELECT, WHERE, ORDER BY)  
- Semana 3-4: SQL intermediário (JOIN, GROUP BY) + Excel avançado  

**Mês 2 - Prática**  
- Semana 5-6: Relatórios SQL + primeiros gráficos no Power BI  
- Semana 7-8: Dashboards simples + introdução ao Python (Pandas)  

**Mês 3 - Portfólio e Preparação**  
- Semana 9-10: Mini-projeto de análise de dados reais  
- Semana 11-12: Dashboard final + simulação de entrevistas  

---

## 🚀 Projeto de Portfólio

**Projeto:** Dashboard de Vendas e Clientes  

**Escopo:**  
- Usar dataset público (ex: Kaggle)  
- Criar consultas SQL para métricas  
- Construir dashboard em Power BI  

**Entregáveis:**  
- Base de dados organizada  
- Relatório SQL  
- Dashboard interativo  

**Critérios de Aceitação:**  
- KPIs claros (receita, clientes ativos)  
- Visualização intuitiva  
- Documentação simples dos insights

## 💬 Roteiro de Entrevistas

**Pergunta 1:** Você já trabalhou com SQL?  
**Resposta:** Explique consultas básicas que domina e cite exemplos práticos.  

**Pergunta 2:** Como você lidaria com dados faltantes?  
**Resposta:** Cite técnicas como substituição por média, exclusão ou análise de impacto.  

**Pergunta 3:** Qual ferramenta de visualização você prefere?  
**Resposta:** Power BI, explicando como usou para criar dashboards.  

**Pergunta 4:** Conte um exemplo de problema resolvido com dados.  
**Resposta:** Relate situação prática mostrando raciocínio lógico.  

**Pergunta 5:** Como você garante qualidade dos dados?  
**Resposta:** Validação, limpeza e consistência entre fontes.
